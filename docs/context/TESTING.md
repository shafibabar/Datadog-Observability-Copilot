# TESTING.md — TDD discipline & metrics log

## Protocol (binding)
- **Regression invariant:** once a test is green it stays green. Every step runs the full suite (`pytest`); previously-passing tests must never break.
- **Test-first:** for each new capability, write the failing spec tests first (red), then implement to green. (The Iteration 0 *foundation* tests were retrofitted — noted honestly below — everything from the reasoning engine onward is genuinely test-first.)
- **Honest metric:** each step reports `passing / total (%)`. If the pass % drops *because new red spec tests were added for a new requirement*, that is stated explicitly — it is expected TDD behavior, not regression.
- **Pending tests** (spec written ahead of implementation) are marked `@pytest.mark.pending` so red-by-design specs are mechanically distinct from real breakage.
- **This log is enforced by a pre-commit hook.** Staging anything under `tests/` without staging this file fails the commit (`scripts/check_testing_log.py`, specs in `tests/test_hooks.py`). Added 2026-08-05 after three passes of test changes landed unlogged — the failure mode was forgetfulness, so the fix is mechanical rather than a stronger promise. Enable once per clone:
  ```
  git config core.hooksPath .githooks
  ```
  Genuine exceptions (a rename, a typo, a fixture tweak mid-step) bypass with `git commit --no-verify`.

## How to run
```
source .venv/bin/activate
pip install -r requirements-dev.txt
pytest                 # full suite
pytest -q              # quiet
pytest tests/test_config.py::test_defaults_when_unset   # a single test
pytest --cov=app       # with coverage (historically ~99% on the product app)
```

**Test layers:** unit (models, guard, scope, adapters, store, personas, artifacts — Datadog HTTP mocked, LLM faked) · functional (FastAPI endpoints via `TestClient` with a fake-LLM `Copilot` over replay data) · declarative **UI-contract** (`tests/test_web_ui.py`, asserts served markup/JS). Optional real-browser smoke: `tests/test_smoke_playwright.py` (SKIPPED unless `playwright` + a browser are installed).
